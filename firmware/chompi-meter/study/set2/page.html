CIRCLES
Set 2

Fourteen electronic sounds for the white keys: a drum machine on keys 1–8, FM, acid and chip sounds for melodies on keys 9–14. They answer to the same six knobs as set 1. Each clip plays the sound as it would come up, then turns one knob, at the dashed line. Mark each one Keep, Maybe or No and add a note. I read the answers from here.

In circles

Loops at CIRCLES' lengths, as you would play them: each player's ratio of L0 is in its name.

How these were made. Rendered on the computer from the C++ that would go into the firmware (study/synths.h), through CIRCLES' own pan and room. Nothing is in the firmware yet.

CPU is measured on the computer against one mallet voice of set 1. Set 1's gangsa costs ×2.6 on the same scale, so anything near that fits as well as set 1 does. The CHOMPI's own numbers come later, from the bench firmware.

The knobs under each card are where that sound comes up: K1 strike, K2 bright, K3 decay, and in orange the CHOMPI layer: shimmer, feel, prep.
