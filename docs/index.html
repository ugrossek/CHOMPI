Feed the CHOMPI

Send a firmware over USB, keep it in one of the launcher's fifteen slots, and start it right away. Send to the same slot again and the new version replaces the old one.

Not connected yet.

  1. Connect

    Turn CHOMPI on with the launcher showing, plug it into this computer, then connect. Your browser will ask to allow MIDI; say yes.

  2. Choose a firmware

    Drop a .bin here, or

    Or install a stock firmware from the CHOMPI repository:

  3. Pick a slot and a name

    Press a key on the CHOMPI above. Whatever is in that slot now will be replaced.

    The file will be called NN_NAME.bin. Use A–Z, 0–9, - and _.

  4. Send it

    CHOMPI's keys fill cyan as the firmware arrives and amber while it's written to the card. Then it starts.
